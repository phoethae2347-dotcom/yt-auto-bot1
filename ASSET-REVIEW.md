# Licensed visual asset review

The former bundled `images/` directory was removed. The current visual pool is `licensed-images/cc0_01.jpg` through `cc0_08.jpg`.

## Source and license

All eight files were retrieved from individual Wikimedia Commons file pages whose API metadata reported **CC0 1.0 Universal Public Domain Dedication**. The source page URL, download URL, creator field, license URL, and SHA-256 hash for each file are recorded in `asset-licenses.json`.

The selected files are nature and landscape scenes rather than identifiable-person portraits. A visual check found forest, valley, mountain, road, sky, and sunset scenes with no obvious identifiable people or private interiors. This is a suitability check, not a legal opinion.

## Reuse conditions

CC0 is a copyright dedication that generally permits commercial reuse and adaptation, but copyright is not the only possible restriction. Before publishing, the channel owner must still check the source page and final edit for privacy, publicity/personality rights, trademarks, logos, private locations, and any local-law issue. Do not use a scene in a way that falsely implies endorsement by the creator or location.

The bot will refuse an asset that is not listed in the verified manifest. Background music is currently disabled because no music file has a verified license record. The video therefore uses narration-only audio until a separate licensed music source is added.

## Verification date

The asset records were retrieved and reviewed on 2026-08-23. If a source page, file, or license status changes, update the manifest and re-run the integrity tests before publishing.
